FIREBASE STORAGE RULES — REVIEW AND TEST BEFORE PUBLISHING

rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    match /postMedia/{userId}/{fileName} {
      allow read: if request.auth != null;
      allow create: if request.auth != null
        && request.auth.uid == userId
        && request.resource.size < 5 * 1024 * 1024
        && request.resource.contentType.matches('image/.*');
      allow update, delete: if request.auth != null
        && request.auth.uid == userId;
    }
  }
}

These rules allow signed-in users to read post images. Consider a stricter access model
if you add private accounts or audience-specific posts. Test rules before public use.
